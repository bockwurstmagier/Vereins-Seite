# MatchCenter Pro v9.1.0

1. `sql/VERSION-9.1.0-MATCHCENTER-PRO.sql` im Supabase SQL Editor ausführen.
2. Patch-Dateien in das Projekt kopieren.
3. `npm run build` ausführen.
4. Mit Git committen und pushen.

Unter `/admin/match-center/[spiel-id]` Formation wählen, Spieler zur Startelf oder Bank hinzufügen und per Finger/Maus verschieben. Die öffentliche Match-Center-Seite zeigt die Formation ebenfalls.
