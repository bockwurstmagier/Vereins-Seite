# Installation – Admin 2.0

Für diese Version ist kein neues SQL notwendig.

1. Bestehende `.env.local` beibehalten.
2. Abhängigkeiten installieren und Projekt prüfen:

```bash
npm install
npm run build
npm run dev
```

3. Adminbereich öffnen:

```text
http://localhost:3000/admin
```

Die eingeklappte Sidebar wird im Browser gespeichert und bleibt beim nächsten Besuch erhalten.
