# HUJA v23.6.3 – Installation

1. Den Inhalt des Patch-ZIPs in das bestehende HUJA-Projekt kopieren und vorhandene Dateien ersetzen.
2. `npm ci`, `npm audit` und `npm run build` ausführen.
3. Mit `git add -A`, `git commit -m "HUJA v23.6.3 - Mobile Battery Performance"` und `git push origin main` veröffentlichen.
4. In Hostinger manuell „Neu bereitstellen / Redeploy“ auslösen.

Es ist keine SQL-Migration erforderlich.
