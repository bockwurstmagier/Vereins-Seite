# HUJA v22.4.0 – Match Highlights
- Automatischer „HUJA MatchTV – Highlights des Spiels“-Bereich.
- Alle Video-Momente werden gesammelt; während LIVE wächst die Sammlung automatisch.
- Nach Abpfiff bleibt sie als Replay-Sammlung bestehen.
- Admin kann Video-Momente als Top-Moment markieren/entfernen; diese stehen zuerst.
- Direct Camera Capture und Match Story bleiben erhalten.
- Vor Installation SQL `sql/VERSION-22.4.0-HUJA-MATCH-HIGHLIGHTS.sql` ausführen.
