# HUJA v21.1.0 – Matchday Hub

## Neu
- Automatischer Matchday-Hub auf der Startseite
- Vor dem Spiel: Countdown + Ergebnistipp
- Punkte: 5 exaktes Ergebnis, 2 richtige Tendenz
- Saisonweite HUJA-Tipprangliste
- Während des Spiels: direkter LiveCenter-Einstieg + 🔥 ❤️ 👏 ⚽ Reaktionen
- Nach Abpfiff: Übergang zum vorhandenen Spieler-des-Spiels-Voting
- Bestehendes Voting, Analytics, Auth, Rollen und FUSSBALL.DE bleiben erhalten

## Installation
1. `sql/VERSION-21.1.0-HUJA-MATCHDAY-HUB.sql` einmal im Supabase SQL Editor ausführen.
2. Patch kopieren/entpacken.
3. `npm install` bzw. vorhandene Dependencies verwenden.
4. `npm run build`
5. Deployment durchführen.

Die v21.0.0 Fan-Experience-SQL muss bereits installiert sein.
