# Installation Version 5.3

1. Projekt entpacken.
2. Deine vorhandene `.env.local` übernehmen.
3. Im Terminal ausführen:

```bash
npm install
npm run dev
```

4. Öffnen:

```text
http://localhost:3000/fussball
```

5. Auf **Offizielle Daten laden** klicken.

Für FUSSBALL.DE muss keine weitere Umgebungsvariable eingetragen werden.
