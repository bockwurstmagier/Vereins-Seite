# HUJA v21.2.0 – Fanpass & Saison-Challenges

1. Zuerst `sql/VERSION-21.2.0-HUJA-FANPASS-CHALLENGES.sql` einmal im Supabase SQL Editor ausführen.
2. Patch über v21.1.0 kopieren.
3. `npm run build`
4. Deployment wie gewohnt.

## Fanpunkte
- Tipp abgegeben: 1 Punkt
- richtige Tendenz: zusätzlich 2 Punkte
- exaktes Ergebnis: zusätzlich 5 Punkte
- Spieler-des-Spiels-Vote: 3 Punkte
- Live-Reaktionen an einem Spieltag: 2 Punkte pro Spieltag

## Ränge
HUJA Rookie → Kurvenfreund → Matchday-Profi → Stammgast → HUJA-Ultra → Vereinslegende

Der Fanpass ist anonym und browser-/gerätegebunden. Bestehende alte Tipps/Votes vor v21.2.0 können nicht rückwirkend eindeutig einem Fanpass zugeordnet werden; neue Aktionen werden automatisch verknüpft.
