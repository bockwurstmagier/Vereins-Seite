# Vereinsmanager 6.0 – Sportzentrum

## Neu

- dynamischer Spielplan mit Filtern
- eigene Kreisliga-Tabelle im Vereinsdesign
- Tabellenverwaltung im Adminbereich
- Formanzeige der letzten fünf Spiele
- automatische Saisonstatistiken
- Heim-/Auswärtsbilanz
- dynamische Startseiten-Tabelle
- neue Schnellzugriffe für Spielplan und Tabelle
- rollenbasierter Zugriff auf die Tabellenverwaltung

## Datenquelle

FUSSBALL.DE bleibt über das offizielle Widget eingebunden. Die eigene Tabelle wird in Supabase gepflegt, weil für die Kreisliga keine frei dokumentierte API zur Verfügung steht.
