# HUJA v23.0.0 – LiveCenter Pro

## Neu
- Sticky Einhand-Schnellleiste: Tor, Karte, Wechsel, Undo.
- 2-Schritt Tor-Flow: Torschütze → Vorlage → gespeichert.
- „Keine Vorlage“ ist die schnellste Abschlussaktion.
- Gegentor als eigener Schnellbutton.
- Spieler-Favoriten werden lokal auf dem Live-Gerät gespeichert und stehen oben; restliche Spieler bleiben alphabetisch.
- Online/Offline-Anzeige; Schreibbuttons werden offline deaktiviert.
- Haptisches Feedback auf unterstützten Geräten.
- Direktes Rückgängig nach gespeichertem Tor.
- Halbzeit-Check zeigt Spielstand + Ereignisanzahl vor Push.
- Abpfiff-Check zeigt Spielstand + Ereignisanzahl vor Abschluss.
- Wake Lock wird nach Rückkehr in die App erneut angefordert, sofern aktiv.
- Bestehender klassischer Event-Center bleibt als Fallback vollständig erhalten.

Keine neue Supabase-SQL erforderlich.
