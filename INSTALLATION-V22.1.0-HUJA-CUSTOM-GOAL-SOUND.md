# HUJA v22.1.0 – Custom Goal Sound

1. SQL `sql/VERSION-22.1.0-HUJA-CUSTOM-GOAL-SOUND.sql` einmal in Supabase ausführen.
2. Patch einspielen und `npm run build`.
3. Admin → Einstellungen → Eigener Tor-Sound.
4. Sound hochladen und direkt im Admin vorhören.
5. Im LiveCenter wird er automatisch statt `/sounds/goal.wav` verwendet. Fans müssen Live-Sound weiterhin selbst aktiviert haben.

Auth/Rollen bleiben unverändert. Upload ist auf Administrator/Vorstand begrenzt; maximal 8 MB.
